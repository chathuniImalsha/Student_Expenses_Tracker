# 💰 Spendly – Student Expense Tracker

**Track. Save. Spend Smart.**

Spendly is a simple full-stack web application that helps students manage expenses, budgets, savings, and personal finances in one place.

## ✨ Features

* 📊 **Dashboard** – View spending, balance, budget, and financial summaries
* 💸 **Expenses** – Add, edit, delete, categorize, search, and filter expenses
* 📅 **Budgets** – Set monthly budgets and monitor budget usage
* 💰 **Savings** – Set savings goals and track saving progress
* 👤 **Profile** – Manage personal profile information
* ⚙️ **Settings** – Manage application preferences
* 🌙 **Dark Mode** – Switch between Light Mode and Dark Mode
* 🔐 **Authentication** – Secure registration and login with JWT
* 📈 **Reports** – View spending patterns and financial reports

## 🛠️ Tech Stack

**Frontend:** React.js, Vite, React Router, Axios, Recharts, CSS

**Backend:** Node.js, Express.js, MongoDB, Mongoose, JWT

**Tools:** VS Code, Postman, Git & GitHub

## 🎯 Purpose

Spendly is designed to help students:

* Track daily expenses
* Manage monthly budgets
* Set and achieve savings goals
* Understand spending habits
* Make smarter financial decisions

## 🚀 Getting Started

### Clone

```bash
git clone https://github.com/chathuniImalsha/Student_Expenses_Tracker.git
cd Student_Expenses_Tracker
```

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Open **http://localhost:5173**

## 🔐 Environment Variables

Create `.env` files using `.env.example`.

```env
PORT=5000
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
VITE_API_URL=http://localhost:5000/api
```

**Note:** Do not upload `.env` files to GitHub.
